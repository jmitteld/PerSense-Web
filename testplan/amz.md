# Amortization Manual Test Plan — AMZ-001 … AMZ-100

**Setup.** Run PerSense-Web (single binary; open the Amortization screen) side-by-side with the legacy **DOS** Per%Sense (the financial authority — do NOT compare against the Windows version or its help examples). Before every case: click **Clear All** in the web app, reset the DOS worksheet, and set the Computational Settings identically in both programs. Unless a case says otherwise, settings are at defaults: Basis days per year **360**, 1st interest prepaid at settlement **YES**, Interest paid in **Arrears**, Interest on interest **Actuarial**, Balloon / prepayment includes regular pmt **NO**, Exact method **NO**, Rule of 78s **NO**, Auto-calculate off. **BASE loan** shorthand = Amt Borrowed 100000, Loan Date 01/01/2025, Rate % 8, 1st Pmt Date 02/01/2025, # Periods 360, Pmts/Yr 12, Pmt Amount blank, Points 0. "Match DOS" means the computed payment, every schedule row (#, Date, Payment, Interest, Principal, Balance, Int to Date), and the totals line agree with the DOS app to the cent (spot-check the first 3 rows, any February, a mid-term row, the last 2 rows, and the totals). Where a case touches a **documented deliberate divergence**, the Expected column says so — do not file those as bugs, but do record the DOS output. Dates are typed MM/DD/YYYY.
