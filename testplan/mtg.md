# Mortgage Worksheet — Manual Test Cases (MTG-001 … MTG-100)

**Tester setup:** Run PerSense-Web and the legacy DOS Per%Sense side-by-side. All cases run on the web **Mortgage** screen (a 12-row grid with columns **Price, Points, % Down, Cash Required, Amt Borrowed, Years, Loan Rate, Mo Tax+Ins, Monthly Total, Balloon Yrs, Balloon Amt, APR**). Enter rate-type fields (**Loan Rate, % Down, Points**) as percent numbers (type `7` for 7%). Leave a field **blank** to have it solved; computed cells render green ("cell-output"). Toolbar buttons: **Calculate Row, Calculate All, Compare APR, What-If Table, Export CSV, Undo, Clear Row, Clear All**. Double-click (or press **H**) hardens a green cell into a fixed input; **C**/**F10** calculates the selected row; **Shift+Delete** clears a cell; **Ctrl/⌘+Z** undoes. Unless a case says otherwise, "matches DOS" means: type the identical inputs into the DOS Mortgage screen and confirm every solved cell agrees to the cent (money) or to displayed precision (percent/APR). Where a case touches a *known deliberate difference*, the Expected column says so explicitly — do not log those as defects. Reset with Clear All between cases unless the case builds on the prior one. Keep the Settings "Auto-calculate" checkbox **off** except where a case turns it on.
